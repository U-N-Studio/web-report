# L3: 正交维度

> 正交维度与基准维度**无关联**，独立评分、独立标记、独立处置。
> 即使基准维度判为中性，正交维度仍可独立触发处置。
> 正交维度之间也相互独立：一条评论可同时被多个正交维度标记。

## Step 3b: 时事核验

> 在真实性维度评分之前，先核实评论中的事实性命题是否有新闻/事实支撑。
> 核验结果作为信号注入真实性维度，决定是否命中"与权威信源冲突(-0.35)""与时事新闻一致(+0.20)"等信号。

### 核验流程

```
评论 → 提取事实性命题 → 查询核验源 → 返回核验结果
```

### 事实性命题提取

从评论中提取可核验的事实性断言（非主观评价、非情绪表达）：

| 提取规则 | 示例评论 | 提取的命题 |
|----------|----------|-----------|
| 含实体+状态/行为 | "美军吃不饱饭" | 美军伙食保障不足 |
| 含数据/数字 | "xx公司裁员50%" | xx公司裁员比例=50% |
| 含因果断言 | "5G传播病毒" | 5G信号可传播病毒 |
| 含地点+事件 | "xx地发生爆炸" | xx地发生爆炸事件 |
| 纯主观评价 | "这游戏真烂" | 无命题，跳过核验 |
| 纯情绪表达 | "卧槽" | 无命题，跳过核验 |

### 核验源与优先级

| 优先级 | 核验源 | 查询方式 | 返回结果 | 延迟 |
|--------|--------|----------|----------|------|
| 1 | 辟谣平台 | API查询中国互联网联合辟谣平台/微信辟谣 | 已辟谣(证伪) | 低 |
| 2 | 权威新闻库 | API/搜索查询新华社/人民日报/CCTV/环球时报 | 有报道(支撑/矛盾) | 中 |
| 3 | 事实核查机构 | API查询澎湃明查/腾讯较真/有据核查 | 已核查(证伪/证实) | 中 |
| 4 | 通用新闻搜索 | 搜索引擎查询近期新闻 | 有相关报道 | 中 |
| 5 | 官方通报/公告 | 查询gov.cn/部委官网 | 有通报 | 中高 |
| 6 | 无结果 | 所有源均无匹配 | 无法核验 | — |

### 核验结果定义

| 结果 | 标记 | 对真实性维度的影响 | 说明 |
|------|------|-------------------|------|
| **已证伪** | 🔴 REFUTED | 触发"已有辟谣记录(-0.40)" + "与权威信源冲突(-0.35)" | 权威平台已明确否定 |
| **有新闻支撑** | 📗 NEWS_SUPPORTED | 触发"与时事新闻一致(+0.20)"，**不触发**"与权威信源冲突" | 近期有新闻报道方向一致 |
| **有新闻矛盾** | 📕 NEWS_CONTRADICTED | 触发"与权威信源冲突(-0.35)" | 近期新闻报道方向相反 |
| **部分支撑** | 📙 NEWS_PARTIAL | 触发"与时事新闻一致(+0.20)" + "数据不可验证(-0.15)" | 新闻方向一致但细节无法验证 |
| **无法核验** | ⚪ UNVERIFIABLE | 不注入额外信号 | 所有源均无匹配，保持默认 |

### 核验结果对意图维度的影响

| 核验结果 | 对意图的影响 | 说明 |
|----------|-------------|------|
| 已证伪 | 意图分值+0.15 | 散布已证伪信息，意图偏向恶意 |
| 有新闻支撑 | 意图分值-0.10 | 有事实依据，反讽/恶意判定降级 |
| 有新闻矛盾 | 意图分值+0.10 | 与新闻矛盾，可能为无知或故意 |
| 部分支撑 | 不调节 | |
| 无法核验 | 不调节 | |

### 核验时效

| 时效窗口 | 说明 | 示例 |
|----------|------|------|
| 7天内 | 热点时事，新闻密度高 | 突发事件、政策发布 |
| 30天内 | 常规新闻，仍有报道 | 经济数据、行业动态 |
| 1年内 | 周期性话题，偶有更新 | 军事动态、国际关系 |
| 历史事实 | 非时效性，查百科/论文 | 历史事件、科学事实 |

> 美军后勤问题属于**1年内**时效窗口（军事动态），需查询近期相关报道。

### 核验缓存

为避免重复查询，核验结果按命题哈希缓存：

```
缓存key = hash(标准化命题)
缓存value = {核验结果, 核验源, 核验时间, 过期时间}
缓存过期 = 核验时间 + 时效窗口
```

## 正交维度1：客观主观维度

> 独立于基准维度的正交维度，基于辩证法衡量言论的思维质量。
> 与法律道德维度正交：一条评论可以合法但极端主观（如饭圈控评），也可以违法但论证客观（如学术引用违禁文献）。

衡量言论从辩证客观到极端主观的光谱。用于识别二极管思维、饭圈极端化、绝对化表达等
破坏讨论生态的模式。

分值范围 **[0, 1]**，保留两位小数。**0 = 完全辩证客观，1 = 完全极端主观**。

### 辩证法三原则对照

| 辩证法原则 | 客观表现(低分) | 主观违背(高分) | 识别特征 |
|-----------|---------------|---------------|----------|
| 对立统一 | 承认事物的两面性，既看优点也看缺点 | 非黑即白，全好或全坏 | "完美""一无是处""永远垃圾" |
| 质量互变 | 承认程度差异和边界条件 | 绝对化，无视程度和条件 | "所有""任何""绝不""一定" |
| 否定之否定 | 承认发展变化，不固化判断 | 静止固化，一锤定音 | "注定""永远""不可能改变" |

### 分级定义

| 编号 | 级别 | 分值区间 | 定义 | 典型表现 | 典型群体 |
|------|------|----------|------|----------|----------|
| O01 | 辩证客观 | [0.00, 0.15) | 多角度分析，承认复杂性，有理有据 | "这个方案有优点也有不足，优点是xx，不足是xx" | 理性讨论者 |
| O02 | 倾向性客观 | [0.15, 0.30) | 有明确立场但论证充分，承认对方合理之处 | "我更倾向A，但B也有道理，只是xx情况下A更合适" | 理性支持者 |
| O03 | 主观偏好 | [0.30, 0.45) | 表达偏好但不攻击异见，论证较弱 | "我就是喜欢这个，不喜欢那个" | 普通用户 |
| O04 | 情绪化站队 | [0.45, 0.60) | 强烈站队，拒绝考虑异见，但无攻击行为 | "xx天下第一！其他都是垃圾" | 狂热粉丝 |
| O05 | 二极管思维 | [0.60, 0.75) | 非黑即白，非友即敌，拒绝灰色地带 | "不支持就是反对""你不用就是黑" | 二极管/极端粉 |
| O06 | 饭圈攻击 | [0.75, 0.90) | 有组织的极端站队，攻击异见者，控评洗地 | "家人们冲！把黑评踩下去""脱粉回踩" | 饭圈/黑粉 |

## 正交维度2：意图维度

> 正交维度。衡量言论字面意思与真实意图之间的距离。
> 与法律道德维度正交：同一句话"你可真行"可以是真诚赞美(正向)也可以是阴阳怪气(违反道德)；
> 与客观主观维度正交：讽刺可以很辩证(客观主观分值低)，但意图仍是攻击。

分值范围 **[0, 1]**，保留两位小数。
**0 = 字面即意图（表里如一），1 = 意图高度隐蔽（言此意彼）**。

### 意图光谱

| 编号 | 级别 | 分值区间 | 定义 | 典型表现 | 示例 |
|------|------|----------|------|----------|------|

| I02 | 含蓄表达 | [0.10, 0.25) | 委婉表达，但意图可被正常识别 | 委婉批评、暗示、留白 | "还有提升空间""不太理想" |
| I03 | 幽默调侃 | [0.25, 0.40) | 用幽默/夸张表达，善意可辨 | 梗、段子、善意吐槽 | "这是人类能做出来的？"（笑） |

### 意图维度评分方法

意图维度采用 **特征信号累加评分**，从 0.00 起步，命中特征信号则累加权重，
最终 clamp 到 [0.00, 1.00]。

#### 特征信号表

| 信号编号 | 信号 | 权重 | 说明 | 示例 |
|---------|------|------|------|------|
| sig1 | 褒贬冲突 | +0.20 | 字面褒义但语境为贬，或反之 | "可太棒了"（配负面语境） |
| sig2 | 反讽语气词 | +0.15 | 匹配反讽语气模式 | "真是绝了""佩服佩服""厉害厉害" |
| sig3 | emoji语义冲突 | +0.10 | emoji与文字语义方向相反 | "👍"配批评文字、"😊"配攻击语境 |
| sig4 | 不点名暗指 | +0.20 | 不直接提对象但明显指向 | "有些人啊""懂的都懂""大家心知肚明" |
| sig5 | 假意礼貌 | +0.15 | 表面礼貌/关心但语境为攻击 | "请问您是怎么做到的""心疼xx一秒" |
| sig6 | 先扬后抑 | +0.10 | 前半肯定后半否定 | "人是挺好的，就是..." |
| sig7 | 反问施压 | +0.10 | 用反问表达否定 | "你觉得这样合适吗" |
| sig8 | 暗语匹配 | +0.30 | 匹配审核规避暗语库 | "伞兵""nmsl""s.b" |
| sig9 | 重复强化 | +0.05 | 同一反讽模式重复出现 | "厉害厉害""很好很好" |
| sig10 | 对话对象敌意 | +0.10 | 与对话对象有历史冲突/对立立场 | 回复链中前序评论为对骂 |

#### 评分公式

```
I_intent = clamp(0.00 + Σ(命中信号的权重), 0.00, 1.00)
```

#### 评分示例

| 评论 | 命中信号 | 计算 | 意图分值 | 判定 |
|------|---------|------|---------|------|
| "这个做得好" | 无 | 0.00 | 0.00 | 直白表达 |
| "这是人类能做出来的？"（笑） | sig2(+0.15) | 0.15 | 0.15 | 幽默调侃 |
| "可太厉害了，佩服佩服" | sig1(+0.20) + sig2(+0.15) + sig9(+0.05) | 0.40 | 0.40 | 反讽 |
| "有些人啊，自己心里清楚" | sig4(+0.20) | 0.20 | 0.20 | 含蓄表达→需语境 |
| "有些人啊，自己心里清楚"（回复对立用户） | sig4(+0.20) + sig10(+0.10) | 0.30 | 0.30 | 含蓄表达→偏反讽 |
| "请问您是怎么做到的？"（回复被批评者） | sig5(+0.15) + sig10(+0.10) | 0.25 | 0.25 | 含蓄表达 |
| "你可千万别累着，心疼您一秒" | sig2(+0.15) + sig5(+0.15) | 0.30 | 0.30 | 含蓄表达→偏反讽 |
| "你可千万别累着，心疼您一秒👍" | sig2(+0.15) + sig5(+0.15) + sig3(+0.10) | 0.40 | 0.40 | 反讽 |
| "你说得都对👍" | sig1(+0.20) + sig5(+0.15) + sig3(+0.10) | 0.45 | 0.45 | 反讽→偏阴阳 |
| "你说得都对👍"（回复长期对立者） | sig1(+0.20) + sig5(+0.15) + sig3(+0.10) + sig10(+0.10) | 0.55 | 0.55 | 阴阳怪气 |
| "有些人啊，自己心里清楚👍"（回复对立者） | sig4(+0.20) + sig3(+0.10) + sig10(+0.10) | 0.40 | 0.40 | 反讽 |
| "懂的都懂，我就不说什么了👍" | sig4(+0.20) + sig4(+0.20) + sig3(+0.10) | 0.50 | 0.50 | 反讽→偏阴阳 |
| "伞兵" | sig8(+0.30) | 0.30 | 0.30 | 含蓄→但触发暗语还原 |
| "nmsl" | sig8(+0.30) | 0.30 | 0.30 | 含蓄→但触发暗语还原 |

> **暗语还原升级**：sig8 命中时，基础意图分值可能不高，但触发暗语还原后
> 若还原结果命中违法关键词，意图分值直接提升至 0.85+（隐蔽攻击）。

#### 语境信号的获取

| 信号 | 获取方式 | 可靠度 |
|------|----------|--------|
| 褒贬冲突 | AI 语义分析：字面情感 vs 语境情感 | 高 |
| emoji语义冲突 | emoji 情感极性 vs 文字情感极性 | 中高 |
| 对话对象敌意 | 回复链分析：前序评论是否为对立立场 | 中 |
| 反讽语气词 | 正则匹配语气词模式库 | 高 |
| 不点名暗指 | 检测代词("有些人"/"懂的都懂") + 无明确指代对象 | 中 |
| 暗语匹配 | 谐音/缩写/拆字还原 + 敏感词库匹配 | 高 |

### 意图维度的判定逻辑

此维度独立输出，不调节也不依赖基准维度分值：

| 意图分值 | 标记 | 独立处置 |
|---------|------|----------|
| [0.00, 0.25) | 无标记 | 不干预 |
| [0.25, 0.40) | 幽默调侃 | 不干预，可标记"调侃"用于内容分析 |
| [0.40, 0.55) | 反讽 | 标记"反讽"，不改变展示 |
| [0.55, 0.70) | 阴阳怪气 | 折叠 + 标记"阴阳怪气" |
| [0.70, 0.85) | 冷暴力 | 折叠 + 标记"冷暴力" + 人工复核 |
| [0.85, 1.00] | 隐蔽攻击 | 折叠 + 标记"隐蔽攻击" + 人工复核 + 触发暗语还原告警 |

**隐蔽攻击的特殊处理**：意图分值 ≥ 0.85 时，触发暗语还原流程：
1. 将谐音/缩写/拆字等暗语还原为原始词
2. 还原后的内容重新送入基准维度评分
3. 若还原后命中违法段，升级为违法处置（此时与基准维度联动，因为还原后字面已变）

## 正交维度3：真实性维度

> 正交维度。衡量言论内容与事实的吻合程度。
> 与法律道德维度正交：造谣可以很礼貌（法律道德分值高但真实性低），粗话可以说的真话（真实性高但法律道德分值低）。
> 与客观主观维度正交：主观观点可以基于事实（主观但真实），客观陈述可能是假的（客观但不真实）。
> 与意图维度正交：善意转发也可能是假消息（意图好但真实性低）。

真实性维度拆分为两个子维度：**科学维度**（事实与逻辑）和 **信息维度**（信源与可溯源性），
取两者加权平均作为最终真实性分值。

分值范围 **[0, 1]**，保留两位小数。
**0 = 完全虚假，1 = 完全真实**。与正交维度1/2方向相反：越高越好。

### 子维度A：科学维度

衡量言论在事实准确性和逻辑自洽性上的可靠程度。不关心信息来源，只关心内容本身是否成立。

| 编号 | 级别 | 分值区间 | 定义 | 典型表现 |
|------|------|----------|------|----------|
| SA01 | 违背基本定律 | [0.00, 0.10) | 违反已确立的科学/数学/逻辑定律 | 永动机、1+1=3、时间倒流 |
| SA02 | 伪科学 | [0.10, 0.25) | 披着科学外衣但结论不成立 | "碱性水治癌""量子波动速读" |
| SA03 | 因果谬误 | [0.25, 0.40) | 因果关系不成立或倒置 | "因为下雨所以地震""吃xx导致xx"（无因果） |
| SA04 | 数据失真 | [0.40, 0.55) | 数据存在但严重失真/选择性引用 | "90%的人支持"（样本偏倚） |
| SA05 | 细节偏差 | [0.55, 0.70) | 核心事实正确，非核心细节有误 | 时间误差、数字四舍五入偏差 |
| SA06 | 逻辑自洽 | [0.70, 0.85) | 逻辑无矛盾，与已知事实不冲突 | 合理推断、经验性陈述 |
| SA07 | 事实确证 | [0.85, 1.00] | 可重复验证/数学证明/定义性真命题 | 物理常数、数学定理、定义事实 |

**科学维度特征信号**：

| 信号 | 权重(扣减) | 说明 | 示例 |
|------|-----------|------|------|
| 违背物理/化学/生物定律 | -0.40 | 与已确立自然定律矛盾 | "水变油""永动机" |
| 统计谬误 | -0.25 | 样本偏倚/幸存者偏差/混淆变量 | "吃xx的人都长寿"（忽略其他因素） |
| 因果倒置 | -0.20 | 将结果当原因 | "因为成绩好所以补课"（因果可能相反） |
| 逻辑矛盾 | -0.20 | 内部自相矛盾 | "我绝对不说绝对" |
| 选择性引用 | -0.15 | 只引用有利数据，忽略不利数据 | 只提成功案例不提失败率 |
| 与常识冲突 | -0.15 | 与广泛验证的常识矛盾 | "地球是平的" |
| 可验证数据 | +0.20 | 数据有公开来源可查 | "据国家统计局数据" |
| 逻辑自洽 | +0.15 | 推理链条无断裂 | 前提→推导→结论均成立 |
| 与已知事实一致 | +0.20 | 与已验证知识库吻合 | 与教科书/论文一致 |

**科学维度评分**：
```
S_science = clamp(0.50 + Σ(信号权重), 0.00, 1.00)
```

### 子维度B：信息维度

衡量言论在信息来源可靠性、可溯源性上的可靠程度。不关心内容本身是否科学，只关心信息从哪来、是否可查证。
覆盖新闻信源，也覆盖非新闻场景：个人经验陈述、技术文档引用、社区知识传播等。

| 编号 | 级别 | 分值区间 | 定义 | 典型表现 |
|------|------|----------|------|----------|
| NB01 | 已辟谣 | [0.00, 0.10) | 权威平台已明确证伪 | 12377/辟谣平台有辟谣记录 |
| NB02 | AI伪造 | [0.10, 0.20) | 深度伪造/AI生成冒充真实 | 深伪视频、AI编造新闻 |
| NB03 | 伪造权威 | [0.20, 0.30) | 假冒官方/专家名义 | "专家表示"（无姓名/机构/链接） |
| NB04 | 匿名/无源 | [0.30, 0.40) | 无出处或来源完全不可追溯 | "据说""网上都在说" |
| NB05 | 单一信源 | [0.40, 0.55) | 有来源但仅一家，未交叉验证 | 单一自媒体引用 |
| NB06 | 多源未验证 | [0.55, 0.70) | 多个来源但均为二手/非权威 | 多个自媒体引用同一未知来源 |
| NB07 | 权威信源 | [0.70, 0.85) | 有权威媒体/官方通报佐证 | 新华社/人民日报/政府通报 |
| NB08 | 交叉验证 | [0.85, 1.00] | 2+独立权威信源交叉验证 | 新华社+央视+当事方确认 |

**信息维度特征信号**：

信号分为两类：**外部信号**（独立于评论信源，由第三方权威平台判定）和**内部信号**（依赖评论自身信源质量）。

| 信号 | 类型 | 权重(扣减) | 说明 | 示例 |
|------|------|-----------|------|------|
| 已有辟谣记录 | 外部 | -0.40 | 权威平台已辟谣，与信源无关 | 12377/微信辟谣有记录 |
| 深伪/AI生成痕迹 | 外部 | -0.35 | 技术检测到伪造，与信源无关 | 视频帧不一致、GAN伪影 |
| 与权威信源冲突 | 外部 | -0.35 | 与官方通报/权威报道矛盾，与信源无关 | 与新华社报道相反 |
| 假冒官方名义 | 外部 | -0.30 | 无链接/无署名的"官方" | "官方通知"（无gov.cn链接） |
| 图片/视频篡改 | 外部 | -0.25 | PS/剪辑/移花接木 | EXIF不一致、拼接痕迹 |
| 跨语境嫁接 | 外部 | -0.25 | 旧闻冒充新闻/国外冒充国内 | 2019年图配2024年文 |
| 无信息来源 | 内部 | -0.15 | 声称事实但无出处 | "已经确认了"（无链接） |
| 来源不可靠 | 内部 | -0.20 | 自媒体/匿名/营销号 | "据xx博主透露" |
| 与时事新闻一致 | 内部 | +0.20 | 与近期新闻报道方向一致（即使细节有出入） | 近期有新闻报道称美军后勤困难 |
| 有可靠来源链接 | 内部 | +0.20 | 附带权威URL | 附新华社链接 |
| 多信源交叉验证 | 内部 | +0.25 | 2+独立信源确认 | 新华社+当事方声明 |
| 当事人陈述 | 内部 | +0.30 | 评论者即当事人 | "我是当事人" |
| 与权威信源一致 | 内部 | +0.20 | 与官方通报吻合 | 与政府通报一致 |

**信息维度评分**：
```
S_info = clamp(0.50 + Σ(外部信号权重) + Σ(内部信号权重 × 信源置信度), 0.00, 1.00)
```

> **外部信号**（辟谣/深伪/权威冲突/假冒/篡改/嫁接）：由第三方权威平台或技术检测产出，
> **独立于评论信源**，全额生效不乘S_n。营销号发已辟谣内容，"已有辟谣记录(-0.40)"全额扣减。
>
> **内部信号**（来源可靠性/新闻佐证/交叉验证）：依赖评论自身信源质量，
> 需乘信源置信度S_n。"据新华社报道"的"与权威信源一致(+0.20)"×0.95=+0.19，
> "据xx博主透露"的"与时事新闻一致(+0.20)"×0.20=+0.04。

### 新闻机构置信度体系

不同新闻机构的可信度差异巨大，"有新闻佐证"必须区分是**新华社**佐证还是**营销号**佐证。

#### 新闻机构置信度分级

| 级别 | 置信度 | 机构类型 | 典型机构 | 特征 |
|------|--------|----------|----------|------|
| **S1 国级官媒** | 0.95 | 国家级官方媒体，有采编规范和事实核查制度 | 新华社、人民日报、央视、光明日报 | 有采编规范、有更正机制、有事实核查流程 |
| **S2 部级/省级官媒** | 0.85 | 部委/省级官方媒体 | 中国新闻网、各省级党报、环球时报 | 有采编规范，但可能带部门/地方立场 |
| **S3 专业财经媒体** | 0.80 | 财经类专业媒体，有数据核查传统 | 财新、第一财经、经济观察报 | 有数据核查，但财经报道可能滞后 |
| **S4 主流商业媒体** | 0.70 | 大型商业媒体，有采编团队 | 澎湃、界面、南方周末 | 有采编团队，但商业压力可能影响选题 |
| **S5 地方都市报** | 0.65 | 地方都市报/晚报 | 各城市晚报、都市报 | 本地新闻可靠，全国/国际新闻为二手 |
| **S6 事实核查机构** | 0.90 | 专门从事事实核查 | 澎湃明查、腾讯较真、有据核查 | 核查方法论透明，但覆盖范围有限 |
| **S7 外媒(主流)** | 0.65 | 国际主流媒体 | 路透社、AP、BBC、NHK | 国际新闻可靠，涉华报道可能有立场 |
| **S8 外媒(其他)** | 0.40 | 非主流外媒 | 各国地方媒体、立场鲜明媒体 | 需交叉验证 |
| **S9 网络媒体(有采编)** | 0.55 | 有采编团队的网媒 | 澎湃新闻(web)、搜狐原创 | 有采编但网媒更正机制弱 |
| **S10 自媒体/营销号** | 0.20 | 无采编规范，以流量为导向 | 各平台营销号、百家号/头条号低质号 | 无事实核查，大量转载/编造 |
| **S11 匿名/无法溯源** | 0.10 | 无署名、无机构、无法验证 | "网友爆料""据内部人士" | 完全无法验证 |

#### 置信度对信号权重的影响

信源置信度作为**内部信号**权重的乘数（外部信号全额生效，不乘S_n）：

```
外部信号实际权重 = 信号基准权重（全额生效）
内部信号实际权重 = 信号基准权重 × 信源置信度(S_n)

示例：
  辟谣平台有记录 → "已有辟谣记录" 基准-0.40（外部，全额生效）= 实际-0.40
  "据新华社报道" → "与权威信源一致" 基准+0.20 × S1(0.95)（内部）= 实际+0.19
  "据xx博主透露" → "与时事新闻一致" 基准+0.20 × S10(0.20)（内部）= 实际+0.04
  "据内部人士" → "有可靠来源链接" 基准+0.20 × S11(0.10)（内部）= 实际+0.02
```

> 关键效果：**同一信号，新华社佐证权重是营销号的4.75倍**。防止"有新闻佐证"被低质信源滥用。

#### 多信源综合置信度

当多个信源佐证同一命题时：

```
S_combined = 1 - Π(1 - S_n)  （概率并集公式）

示例：
  新华社(0.95) + 央视(0.95) → 1 - (1-0.95)×(1-0.95) = 1 - 0.0025 = 0.9975
  新华社(0.95) + 营销号(0.20) → 1 - (1-0.95)×(1-0.20) = 1 - 0.04 = 0.96
  自媒体A(0.20) + 自媒体B(0.20) → 1 - (1-0.20)×(1-0.20) = 1 - 0.64 = 0.36
```

> 两个营销号 ≠ 一个新华社。多低质信源叠加置信度上限约0.36，远低于单一S1。

#### 信源识别规则

| 识别方式 | 优先级 | 说明 |
|----------|--------|------|
| URL域名匹配 | 最高 | xinhua.net→S1, gov.cn→S1, weibo.com/user→S10 |
| 媒体名称匹配 | 次高 | "新华社""人民日报"→S1, "xx博主"→S10 |
| 平台+认证状态 | 中等 | 官方认证+蓝V→提升0.10，无认证→维持原级 |
| AI推断 | 兜底 | 根据文风/排版/引用方式推断 |
| 默认值 | 最低 | 未识别→S11(0.10) |

### 新闻模糊点机制

> 与历史轨道的模糊点机制对称：新闻真实性也不是非真即假，
> 存在大量"有新闻佐证但信源置信度不足"的模糊地带。

#### 新闻模糊点触发条件

> **优先级**：模糊点判定优先于真实性分级判定。当T_truth和S_combined同时满足
> 真实性分级和模糊点触发条件时，**先判模糊点**，再在模糊点内标注真实性级别。

| 条件 | 说明 | 示例 |
|------|------|------|
| S_combined ∈ [0.30, 0.60) | 信源置信度不足，佐证力度有限 | 仅有自媒体报道 |
| T_truth ∈ [0.40, 0.55) | 真实性落入"部分真实"区间 | 有新闻但细节无法验证 |
| 时事核验=有新闻支撑 且 S_combined < 0.50 | 有新闻但信源质量低 | "据xx大V透露" |
| 同一命题不同信源结论矛盾 | 信源之间互相矛盾 | A源说"已确认"B源说"未确认" |

#### 新闻模糊点标记

```
🔶 模糊点：[信源不足/信源矛盾/细节未验证] — [信源置信度S] — [争议说明]

示例：
  🔶 模糊点：信源不足 — S=0.20(营销号) — 仅有自媒体报道，缺乏权威信源交叉验证
  🔶 模糊点：信源矛盾 — S=0.65/0.70 — 官方源未确认，商业媒体已报道，结论矛盾
  🔶 模糊点：细节未验证 — S=0.85 — 新华社已报道核心事实，但具体数字未核实
```

#### 新闻模糊点处置

| 条件 | 处置 | 说明 |
|------|------|------|
| S_combined ≥ 0.80 且 T_truth ≥ 0.55 | 正常展示 | 权威信源+真实性可接受，非模糊点 |
| S_combined ∈ [0.50, 0.80) 且 T_truth ∈ [0.40, 0.55) | 降权+附加"信源待验证" | 有一定佐证但不足 |
| S_combined ∈ [0.30, 0.50) | 降权+附加"仅xx级信源报道，待权威信源验证" | 信源质量明显不足 |
| S_combined < 0.30 | 标记"信息存疑"+折叠+附加辟谣提示 | 信源几乎不可信 |

#### 模糊点 vs 确判

```
新闻真实性判定光谱：

确认虚假 ← 高度可疑 ← 模糊点(信源不足) → 部分真实 → 可信 → 确认真实
   │           │              │                  │          │          │
 T<0.10      T∈[0.10,0.25)  T∈[0.25,0.55)    T∈[0.40,0.55) T∈[0.70,0.85) T≥0.85
 S<0.10      S<0.30         S∈[0.30,0.60)     S≥0.50       S≥0.70       S≥0.85
   │           │              │                  │          │          │
 折叠+辟谣   折叠+提示     降权+信源说明     降权+提示   正常展示   加权推荐
```

> **关键原则**：有新闻≠可确认。低质信源的"新闻佐证"只能触发模糊点，不能直接跳到"部分真实"。
> "据xx博主透露"和"据新华社报道"的判定结果必须显著不同。

### 真实性综合评分

两个子维度加权平均，权重根据内容类型动态调整：

```
T_truth = W_science × S_science + W_info × S_info

其中：
  - 科学/技术/健康类内容：W_science = 0.70, W_info = 0.30
  - 新闻/时事/社会类内容：W_science = 0.30, W_info = 0.70
  - 其他/混合类内容：     W_science = 0.50, W_info = 0.50
```

3. 此时基准维度以"散布谣言"重新评分，不再保持独立

## 正交维度4：表述完整性维度

> 正交维度。衡量言论是否提供了足够的限定条件，使读者能准确理解其含义而不产生歧义或误导。
> 与真实性维度正交：一句话可以真实但极度简略（"美军吃不饱饭"有新闻支撑但缺范围/时态/限定），
> 也可以虚假但表述完整（伪科学文章逻辑严密但结论错误）。
> 与意图维度正交：简略可能是无心省略，也可能是故意断章取义。

分值范围 **[0, 1]**，保留两位小数。
**0 = 极度简略（断章取义风险极高），1 = 表述完整（限定充分，无歧义）**。

### 核心问题

过于简略的表述即使内容有事实支撑，也会因缺少限定条件而造成**断章取义式误导**：

| 简略表述 | 缺少的限定 | 完整表述 | 误导效果 |
|----------|-----------|----------|----------|
| "美军吃不饱饭" | 哪支部队？什么时期？什么情况？ | "2024年某航母部署期间，部分舰员反映伙食供应临时不足" | 暗示美军整体伙食差 |
| "xx公司裁员50%" | 哪个部门？什么时间范围？ | "xx公司客服部门2024年裁员50%，其他部门未受影响" | 暗示公司大规模裁员 |
| "疫苗有副作用" | 什么疫苗？什么副作用？概率？ | "xx疫苗接种后约0.1%出现轻微发热，24小时内自行消退" | 暗示疫苗不安全 |
| "5G有辐射" | 什么频段？多强？和什么比？ | "5G基站辐射约0.1W/m²，远低于国标40W/m²限值" | 暗示5G辐射有害 |

### 分级定义

| 编号 | 级别 | 分值区间 | 定义 | 典型表现 |
|------|------|----------|------|----------|
| C01 | 断章取义 | [0.00, 0.15) | 抽取真实片段但刻意省略关键限定，制造与原意相反的印象 | "专家说xx"（省略前提条件） |
| C02 | 极度简略 | [0.15, 0.30) | 仅陈述结论，无任何范围/条件/时态限定 | "美军吃不饱饭" |
| C03 | 简略 | [0.30, 0.45) | 有部分限定但不足以消除主要歧义 | "某地发生地震"（缺震级/时间） |
| C04 | 基本完整 | [0.45, 0.60) | 限定基本充分，边缘情况可能有歧义 | "xx省今日发生5.2级地震" |
| C05 | 完整 | [0.60, 0.75) | 范围、条件、时态等限定充分，核心含义无歧义 | "2024年xx市记录到5.2级地震，无人员伤亡" |
| C06 | 详尽 | [0.75, 0.90) | 提供完整上下文，包括来源、限定、例外、数据 | 含数据+来源+时间+范围+例外条件 |
| C07 | 严谨 | [0.90, 1.00] | 学术级严谨，所有限定条件显式声明 | 论文式表述，含置信区间/样本量/方法论 |

### 完整性要素检测

对评论逐项检测以下6类限定要素是否缺失：

| 要素 | 检测项 | 缺失扣分 | 示例（缺失→补全） |
|------|--------|---------|-------------------|
| **范围** | 是否限定主体范围（全部/部分/某类） | -0.15 | "美军"→"部分美军舰艇""裁员50%"→"客服部门裁员50%" |
| **时态** | 是否限定时间（当前/过去/某时段/一次性/持续） | -0.15 | "吃不饱"→"部署期间吃不饱""发生地震"→"今日发生" |
| **条件** | 是否限定前提条件（在xx情况下/若xx） | -0.10 | "有副作用"→"极少数人有轻微副作用""不能吃"→"空腹时不能吃" |
| **程度** | 是否限定程度/数量（严重/轻微/多少/比例） | -0.10 | "有辐射"→"辐射值0.1W/m²""涨价"→"涨价约3%" |
| **来源** | 是否标注信息来源 | -0.10 | 无来源→"据xx报道""据xx数据" |
| **例外** | 是否声明例外/反例（除xx外/不适用于xx） | -0.05 | 通常可省略，但争议话题应注明 |

### 评分公式

```
C_completeness = clamp(1.00 + Σ(要素缺失扣分), 0.00, 1.00)
```

> 基准值 1.00 表示"默认完整"，每缺一项要素扣减相应分数。

### 评分示例

| 评论 | 缺失要素 | 计算 | C_completeness | 判定 |
|------|---------|------|----------------|------|
| "美军吃不饱饭" | 范围(-0.15)+时态(-0.15)+条件(-0.10)+程度(-0.10)+来源(-0.10) | 1.00-0.60 | 0.40 | 基本完整边界 |
| "2024年某航母部署期间，部分舰员反映伙食供应临时不足" | 程度(-0.10)+来源(-0.10) | 1.00-0.20 | 0.80 | 详尽 |
| "据新华社报道，xx省今日15时发生5.2级地震，震源深度10km，暂无人员伤亡报告" | 例外(-0.05) | 1.00-0.05 | 0.95 | 严谨 |
| "疫苗有副作用" | 范围(-0.15)+时态(-0.15)+条件(-0.10)+程度(-0.10)+来源(-0.10) | 1.00-0.60 | 0.40 | 基本完整边界 |
| "xx疫苗接种后约0.1%出现轻微发热，24小时内自行消退" | 来源(-0.10)+例外(-0.05) | 1.00-0.15 | 0.85 | 详尽 |
| "5G有辐射" | 范围(-0.15)+时态(-0.15)+条件(-0.10)+程度(-0.10)+来源(-0.10) | 1.00-0.60 | 0.40 | 基本完整边界 |
| "5G基站辐射约0.1W/m²，远低于国标40W/m²限值" | 来源(-0.10) | 1.00-0.10 | 0.90 | 严谨 |
| "这游戏真好玩" | 无事实性命题 | — | 1.00 | 不适用（非事实性陈述） |

> 纯主观评价/情绪表达不含事实性命题，C_completeness = 1.00（不适用，不扣分）。

### 表述完整性对真实性的调节

表述不完整时，即使真实性分值较高，也应降级——因为**部分真实+极度简略 ≈ 误导**：

```
T_adjusted = T_truth × (0.50 + 0.50 × C_completeness)

即：
  C_completeness = 1.00 → T_adjusted = T_truth        （不调节）
  C_completeness = 0.50 → T_adjusted = T_truth × 0.75  （降25%）
  C_completeness = 0.00 → T_adjusted = T_truth × 0.50  （降50%）
```

> 逻辑：完全不完整的表述最多让真实性折半，但不会归零（因为内容本身可能仍为真）。

### 调节示例

| 评论 | T_truth | C_completeness | T_adjusted | 真实性判定变化 |
|------|---------|----------------|------------|---------------|
| "美军吃不饱饭"（有新闻） | 0.54 | 0.40 | 0.54×0.70=**0.38** | 部分真实→存疑 |
| "美军吃不饱饭"（无新闻） | 0.15 | 0.40 | 0.15×0.70=**0.11** | 高度可疑→边界确认虚假 |
| "某航母部署期间部分舰员伙食临时不足" | 0.54 | 0.80 | 0.54×0.90=**0.49** | 部分真实（不降级） |
| "据新华社，xx省今日5.2级地震" | 0.85 | 0.95 | 0.85×0.98=**0.83** | 可信（不降级） |

### 表述完整性维度的判定逻辑

此维度独立输出，不调节基准维度分值，但**调节真实性维度的最终分值**：

| 完整性分值 | 标记 | 独立处置 |
|-----------|------|----------|
| [0.85, 1.00] | 无标记 | 不调节真实性 |
| [0.60, 0.85) | 📝 略有省略 | 不干预，可附加"更完整表述：..." |
| [0.45, 0.60) | 📝 部分简略 | 附加"建议补充范围/时态等限定" |
| [0.30, 0.45) | ⚠️ 简略 | 标记"表述简略" + 附加完整化提示 + 调节真实性 |
| [0.15, 0.30) | 🔶 极度简略 | 标记"表述极度简略" + 附加完整化提示 + 调节真实性 + 降权 |
| [0.00, 0.15) | 🔴 断章取义 | 标记"疑似断章取义" + 附加原文/上下文 + 调节真实性 + 人工复核 |

**断章取义的特殊判定**：完整性分值 < 0.15 时：
1. 检查意图维度：若 I_intent ≥ 0.40（含蓄/反讽以上），标记"故意断章取义"
2. 若同时 T_truth ≥ 0.40（部分真实以上），标记"真话半句=假话"——用真实片段制造虚假印象
