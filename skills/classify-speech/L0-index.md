# Classify Speech Skill

> AI 评论违规分类技能 — 分层架构，按需加载，减少上下文消耗。

## 概述

本技能定义了评论审核中违规言论的分类体系、判定规则、置信度校准和人工复核流程。
采用 **5 层分级架构**，AI 引擎根据判定流程逐层加载，不需要一次性读取全部内容。

**法源依据**：
- 12377 国家互联网违法和不良信息举报中心举报入口分类
- 《网络信息内容生态治理规定》（国家网信办令第5号）第六条（违法信息）、第七条（不良信息）
- 《网络安全法》《反电信网络诈骗法》《个人信息保护法》

## 分层架构

```
L0  L0-index.md (SKILL.md) ← 你在这里：总览 + 判定流程 + 层索引路由
L1  L1-categories.md       ← 违规类别体系 (9大类/34子类 + 严重等级 + 关键词)
L2  L2-base-dimension.md   ← 基准维度 (法律道德维度 + 调节因子1/2 + 词汇表 + 公式)
    L2-history-dimension.md ← 历史内容判定轨道 (历史人物法律边界 + 史料真实性 + 历史完整性)
L3  L3-orthogonal.md       ← 正交维度 (客观主观/意图/真实性 + 模式库 + 信号表 + 评分)
L4  L4-judgment.md         ← 判定规则 (类别规则 + 联动 + 置信度 + 人工复核)
```

### 加载策略

| 判定阶段 | 需加载的层 | 说明 |
|----------|-----------|------|
| 预扫描 | L1 | 只需关键词库，无需评分规则 |
| 语境校验 | L1 + L2 | 需要类别体系 + 调节因子(场景宽容度/过错度) |
| 基准维度评分 | L2 | 只需基准维度 + 调节因子公式 |
| 时事核验 | L3 | 真实性评分前，先核实评论涉及的命题是否有新闻/事实支撑 |
| 正交维度评分 | L3 | 需正交维度规则 + 时事核验结果，与基准独立 |
| 综合判定 | L4 | 需要联动规则 + 置信度校准 + 处置策略 |

## 判定流程

```
输入评论
  │
  ├─ Step 1: 关键词/模式预扫描                      [加载 L1]
  │   ├─ 【语言检测】英文token占比≥60% → 使用英文关键词库，否则使用中文关键词库
  │   ├─ 命中违法关键词库 → 标记候选类别
  │   ├─ 命中模式库（阴阳怪气/暗语/伪科学等）→ 标记候选模式
  │   └─ 无命中 → 跳过预扫描，直接进入 Step 2
  │
  ├─ Step 2: 语境校验（消除误判）                    [加载 L1 + L2]
  │   ├─ 【引用检测】若 Step1 命中违法/模式关键词 → 检测是否为引用讨论/否定引用 → 降级或豁免
  │   ├─ 检查是否在情境惯用语/粗俗口语表内 → 降级或豁免
  │   ├─ 检查内容场景宽容度（调节因子1）→ 调节阈值
  │   ├─ 检查上下文过错度（调节因子2）→ 调节阈值
  │   └─ 【轨道切换】若为历史内容 → 切换到历史轨道（L2-history-dimension.md）
  │
  ├─ Step 3a: 基准维度评分                           [加载 L2]
  │   └─ S_base → 调节因子1 → S_after_scene → 调节因子2 → S_final
  │
  ├─ Step 3b: 时事核验                               [加载 L3]
  │   ├─ 提取评论中的事实性命题
  │   ├─ 查询时事新闻库/辟谣平台/权威信源
  │   ├─ 返回核验结果：{已证伪 / 有新闻支撑 / 无结果}
  │   └─ 将核验结果注入正交维度3（真实性维度）的信号评分
  │
  ├─ Step 3c: 正交维度评分（依赖 3b 核验结果）       [加载 L3]
  │   ├─ 正交维度1：客观主观维度 → O_objective
  │   ├─ 正交维度2：意图维度 → I_intent
  │   ├─ 正交维度3：真实性维度（注入时事核验结果）→ T_truth
  │   └─ 正交维度4：表述完整性维度 → C_completeness
  │
  └─ Step 4: 综合判定                                [加载 L4]
      ├─ S_final ∈ 违法段 → 判定违法，取对应类别
      ├─ S_final ∈ 违反道德段 → 判定不良，取对应类别
      ├─ S_final ∈ 中性段 → 检查正交维度是否独立触发处置
      ├─ S_final ∈ 正向段 → 正常展示
      └─ 【模糊点联动】若 L2/L3 产出模糊点 → 按L4模糊点联动规则处理
          （模糊点不改变S_final分值，只改变最终判定和处置）
```

## 判定体系总览

```
判定体系
├── 【时事轨道】（默认）
│   ├── 基准维度：法律道德维度（独立评分 [0,1]）  → 详见 L2
│   │   ├── 调节因子1：内容场景宽容度（调节基准分值）
│   │   └── 调节因子2：上下文过错度（调节基准分值）
│   └── 正交维度（独立评分，独立处置，不调节基准）  → 详见 L3
│       ├── 正交维度1：客观主观维度（独立评分 [0,1]）
│       ├── 正交维度2：意图维度（独立评分 [0,1]）
│       ├── 正交维度3：真实性维度（独立评分 [0,1]）
│       │   ├── 子维度A：科学维度（事实与逻辑）
│       │   └── 子维度B：信息维度（信源与可溯源性）
│       └── 正交维度4：表述完整性维度（独立评分 [0,1]）
│
└── 【历史轨道】（Step 2 识别为历史内容时切换）  → 详见 L2-history-dimension.md
    ├── 法律边界：古代人物/古代忠义文化符号/近代英烈/当代公众人物 四类分判
    ├── 历史真实性维度：史料可信度 + 学术共识度 + 历史信号表
    ├── 历史完整性维度：史实vs演义 + 时代背景 + 评价维度 + 学术争议状态
    └── 历史置信度：史料充分性 + 学术争议度 + 时代距离 + 演义干扰度
```

- **基准维度**：独立产出分数，是违规判定的核心依据
- **调节因子**：不独立产出分数，只对基准维度的分值做上下文调节
- **正交维度**：独立产出分数，与基准维度无关联，各自独立标记和处置
  - 正交维度可以放宽标准：即使基准维度判为中性，正交维度仍可独立触发处置
  - 正交维度之间也相互独立：一条评论可同时被多个正交维度标记

## 早退优化

以下情况可在早期步骤直接返回，无需加载后续层：

| 早退条件 | 在步骤 | 返回结果 | 无需加载 |
|----------|--------|----------|----------|
| 无关键词命中 且 评论<10字 且 无特殊模式 且 视频标签∉{暴力/暴恐/政治/英烈} | Step 1 | 中性，不干预 | L2-L4 |
| 无关键词命中 且 评论<10字 且 视频标签∈{暴力/暴恐} 且 含正面情绪词 | Step 1 | 不早退，继续走流程 | — |
| S_final ∈ 正向段 且 无正交维度触发条件 | Step 3a | 正向，加权推荐 | L3-L4 |
| 时事核验=已证伪 且 S_final∈违法段 | Step 3b | 违法+虚假，立即删除 | L4 |
| S_final ∈ 违法段低区间[0.00,0.07) 且 置信度≥0.90 | Step 4 | 违法-极严重，立即删除 | — |
