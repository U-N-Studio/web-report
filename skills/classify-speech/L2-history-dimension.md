# L2: 历史内容判定轨道

> 当 Step 2 语境校验识别内容场景为"历史讨论"时，切换到此轨道。
> 历史内容与时事内容在真实性验证、法律边界、完整性要素、置信度校准上均有本质差异。

## 触发条件

| 识别信号 | 说明 |
|----------|------|
| 评论对象为已故历史人物/事件 | "关羽""秦始皇""二战""文革" |
| 内容场景为 C02 教育科普/C04 纪录片 且讨论对象为历史 | 历史区/知识区的历史讨论 |
| 时事核验返回"历史事实，非时事" | Step 3b 识别为历史命题 |
| 评论含历史时期标记 | "三国""明朝""近代""古代" |

## 与时事轨道的核心差异

| 维度 | 时事轨道 | 历史轨道 |
|------|----------|----------|
| 真实性验证 | 辟谣平台/新闻API/官方通报 | 史料考证/学术共识/考古证据 |
| 信息时效 | 7天-1年 | 无时效，跨千年 |
| 法律边界 | 《英烈保护法》保护近代英烈 | 古代人物**不受**该法保护 |
| 完整性要素 | 范围/时态/条件/程度/来源/例外 | 时代背景/史料来源/学术争议状态/评价维度/民间形象vs史实 |
| 置信度依据 | 信源权威度 | 学术共识度 |
| 断章取义风险 | 省略限定导致误导 | 混淆民间演义与正史/脱离时代背景评判 |

## 法律边界：历史人物 vs 英烈

### 四类法律边界

| 类别 | 时间范围 | 法律保护 | 典型人物 | 评价红线 |
|------|----------|----------|----------|----------|
| **古代历史人物** | 远古至1840年 | 无特殊法律保护 | 秦始皇、隋炀帝 | 仅受一般名誉权约束，学术评价不违法 |
| **古代忠义文化符号** | 远古至1840年 | **忠义精神受公序良俗保护** | 关羽、岳飞、文天祥 | 学术批评不违法；**否定/嘲讽其忠义精神→违反道德** |
| **近代英烈** | 1840年至今 | 《英烈保护法》保护 | 董存瑞、黄继光、刘胡兰 | 侮辱诽谤英烈→P04违法，但理性学术讨论仍受保护 |
| **当代公众人物** | 在世或近期逝世 | 名誉权/隐私权 | 在世名人、近期逝世者 | 侮辱诽谤→Q01违法，批评讨论→中性 |

> **古代忠义文化符号**的判定逻辑：这些人物的历史功过可以学术批评（"关羽军事能力有限"→中性），
> 但其**忠义精神**已成为中华文化的核心价值符号，否定/嘲讽忠义精神属于否定公序良俗，
> 适用《规定》第七条(六)"宣扬低俗、庸俗、媚俗内容"或第七条(七)一般不良信息。

### 判定规则

| 评论对象 | 评价性质 | 判定 | 说明 |
|----------|----------|------|------|
| 古代历史人物 | 学术性负面评价 | 中性 | "秦始皇暴虐"→学术观点，不违法 |
| 古代历史人物 | 侮辱性人身攻击 | 违反道德 | "秦始皇就是个傻逼"→即使古代人物，人身攻击仍违反道德 |
| **古代忠义文化符号** | **学术性负面评价（限于具体方面）** | **中性** | "关羽军事能力有限""岳飞政治上不够圆通"→学术观点 |
| **古代忠义文化符号** | **否定/嘲讽其忠义精神** | **违反道德** | "关羽的忠义就是愚忠""岳飞死得活该，谁让他忠心"→否定公序良俗 |
| **古代忠义文化符号** | **侮辱性攻击** | **违反道德** | "关羽就是个傻逼""岳飞是走狗"→人身攻击+否定忠义精神 |
| 近代英烈 | 理性学术讨论 | 中性 | "xx战役的伤亡数据需要考证"→学术讨论，不违法 |
| 近代英烈 | 侮辱诽谤 | 违法(P04) | "xx英烈是假的""xx根本没牺牲"→侵害英烈名誉，违法 |
| 近代英烈 | 民间质疑(无侮辱) | 🔶模糊点→人工复核 | "我觉得xx的事迹有夸张成分"→无侮辱但无学术依据，不确定是否违规 |
| 民间演义/文学形象 | 评价 | 中性 | "《三国演义》的关羽被神化了"→文学评论，不违法 |

### 忠义精神否定 vs 学术批评 vs 争议观点的区分

| 类型 | 特征 | 判定 | 示例 |
|------|------|------|------|
| 学术共识批评 | 批评的方面属史学界定论/主流观点 | 中性 | "秦始皇焚书坑儒"（定论） |
| **争议观点** | 批评的方面属学术争议，无定论 | **模糊点，不默认中性** | "关羽军事不行"（争议，需标记"学术争议"） |
| 学术批评(隐含) | 批评具体方面，未提及忠义但也不否定 | 争议→模糊点；主流观点→中性 | "关羽名不符实"（暗示军事方面，模糊点） |
| 忠义精神否定 | 明确否定/嘲讽/解构其忠义精神本身 | 违反道德 | "关羽的忠义就是愚忠，不值得提倡" |
| 忠义精神嘲讽 | 用反讽/戏谑方式消解忠义精神的价值 | 违反道德 | "忠义？不过是给主子卖命罢了" |
| 忠义精神解构 | 将忠义精神重新定义为负面（奴性/愚昧/被洗脑） | 违反道德 | "所谓的忠义不过是被统治阶级洗脑的结果" |
| 历史局限讨论 | 讨论忠义精神的历史局限性，但不否定其核心价值 | 中性边界→人工复核 | "关羽的忠义有其历史局限性，但精神内核仍有价值" |

> **判定关键**：
> - 批评**具体能力/决策**≠否定**精神价值**，但**争议观点不能默认判中性**
> - "关羽军事不行"是争议观点→标记**模糊点**，置信度<0.50，附加"此观点存在学术争议"
> - "关羽的忠义是愚忠"是否定精神价值→违反道德
> - 分水岭1：评论是否**将忠义精神本身定性为负面**
> - 分水岭2：评论的事实基础是**定论**还是**争议**

## 模糊点机制

> 争议观点不默认判中性，而是标记为**模糊点**，显式暴露其不确定性。
> 模糊点不是违规，也不是中性，而是"**判定依据不足，需显式告知用户**"。

### 模糊点触发条件

| 条件 | 说明 | 示例 |
|------|------|------|
| 学术争议状态 = 争议 | 评论观点属学术争议，无定论 | "关羽军事不行" |
| 学术争议状态 = 少数观点 | 评论观点属少数派，缺乏广泛认同 | "岳飞之死是咎由自取" |
| 历史真实性 T_history ∈ [0.40, 0.55) | 事实基础不足 | "夏朝不存在" |
| 完整性 C_history < 0.30 | 表述极度简略，无法确定评论真实意图 | "名不符实"（哪方面？） |
| 近代英烈民间质疑(无侮辱) | 对英烈事迹提出质疑但无侮辱性表达 | "我觉得xx的事迹有夸张成分" |

### 模糊点标记

```
模糊点标记格式：
  🔶 模糊点：[争议类型] — [争议说明] — [置信度]
  
示例：
  🔶 模糊点：学术争议 — 关羽军事能力评价史学界无定论 — C=0.45
  🔶 模糊点：少数观点 — 岳飞之死咎由自取非主流观点 — C=0.35
  🔶 模糊点：表述模糊 — "名不符实"未限定评价维度，可能是军事/政治/整体 — C=0.40
```

### 模糊点处置

| 置信度 | 处置 | 说明 |
|--------|------|------|
| C ≥ 0.50 | 正常展示 + 附加"此观点存在学术争议"提示 | 有一定依据，不降权 |
| 0.30 ≤ C < 0.50 | 降权展示 + 附加争议说明 | 依据不足，降低传播权重 |
| C < 0.30 | 降权 + 附加争议说明 + 人工复核建议 | 依据严重不足 |

### 模糊点 vs 违规 vs 中性

```
判定光谱：

违规(违法/不良) ←────────── 模糊点 ──────────→ 中性(合规)
  │                    ↑                    │
  │              置信度不足，               │
  │              不确定是否违规，           │
  │              也不确定是否合规           │
  │              必须显式标记               │
```

> 模糊点**不是**中性——中性是"确定合规，不干预"；
> 模糊点是"**不确定是否合规，显式暴露不确定性**"。
> 中性不附加提示，模糊点**必须**附加争议说明。

### 关羽特殊说明

关羽具有**四重身份**，判定时必须区分：

| 身份 | 时间 | 法律地位 | 评价规则 |
|------|------|----------|----------|
| 历史人物关羽 | 三国时期(3世纪) | 古代历史人物 | 学术评价不违法 |
| 忠义文化符号关公 | 宋至今 | **古代忠义文化符号** | 否定忠义精神→违反道德；学术批评具体方面→中性 |
| 民间信仰关圣帝君 | 宋-清(10-19世纪) | 文化符号/宗教形象 | 批评民间神化属文化评论，不违法 |
| 现代商业符号关公 | 当代 | 无特殊法律保护 | "关公名不符实"属文化评论 |

> **P04(侵害英烈名誉)不适用于关羽**。关羽非《英烈保护法》所指"近代以来为民族独立、人民解放英勇牺牲的英雄烈士"。
> 但否定关羽的忠义精神仍违反道德（否定公序良俗），适用《规定》第七条。

## 历史真实性维度

历史内容的真实性不查新闻/辟谣平台，而查**史料/学术/考古**。

### 三级史料可信度

| 级别 | 定义 | 典型来源 | 可信度权重 |
|------|------|----------|-----------|
| **正史/官修史书** | 官方编纂的史书，有编修制度保障 | 《三国志》《史记》《明史》 | 0.85 |
| **私家著述/野史** | 个人撰写，可能带立场但仍有史料价值 | 《世说新语》《容斋随笔》 | 0.55 |
| **民间演义/文学** | 文学创作，不以纪实为目的 | 《三国演义》《封神演义》 | 0.20 |

### 学术共识度

| 共识度 | 定义 | 典型 | 对真实性的影响 |
|--------|------|------|---------------|
| 定论 | 史学界高度一致，有充分史料佐证 | 秦始皇统一六国 | T_truth ≥ 0.85 |
| 主流观点 | 多数学者认同，有史料支撑但存在细节争议 | 关羽军事能力有限 | T_truth ∈ [0.55, 0.85) |
| 学术争议 | 学者意见分歧，各有史料支撑 | 夏朝是否存在 | T_truth ∈ [0.40, 0.55) |
| 少数观点 | 少数学者主张，缺乏广泛认同 | 某些翻案文章 | T_truth ∈ [0.25, 0.40) |
| 无学术支撑 | 无史料依据，纯民间传说/网络杜撰 | "xx是外星人" | T_truth < 0.25 |

### 历史真实性信号表

| 信号 | 权重(扣减) | 说明 | 示例 |
|------|-----------|------|------|
| 与正史记载冲突 | -0.30 | 评论与正史明确记载矛盾 | "关羽没有失荆州"（与《三国志》矛盾） |
| 混淆演义与正史 | -0.25 | 将文学创作当历史事实 | "关羽温酒斩华雄"（演义情节，正史无载） |
| 脱离时代背景 | -0.20 | 用现代标准评判古代行为 | "秦始皇搞基建是为了剥削"（脱离战国背景） |
| 无史料依据 | -0.20 | 纯推测/杜撰，无任何史料支撑 | "秦始皇见过外星人" |
| 选择性引用史料 | -0.15 | 只引用有利史料，忽略不利史料 | 只提关羽忠义不提失荆州 |
| 有正史佐证 | +0.25 | 评论观点与正史记载一致 | "关羽失荆州"（正史有载） |
| 有学术共识支撑 | +0.20 | 观点属史学界主流/定论 | "秦始皇统一六国"（定论） |
| 有考古证据支撑 | +0.25 | 有考古发现佐证 | 二里头遗址→夏朝讨论 |

### 历史真实性评分

```
T_history = clamp(0.50 + Σ(信号权重), 0.00, 1.00)
```

> 基准值 0.50 表示"未考证，默认存疑"。与时事轨道不同，历史命题的"存疑"是常态——许多历史问题永远无法确证。

## 历史表述完整性维度

历史评论的完整性要素与时事不同，核心是**是否区分了史实与演义、是否提供了时代背景**。

### 历史完整性要素

| 要素 | 检测项 | 缺失扣分 | 示例（缺失→补全） |
|------|--------|---------|-------------------|
| **史实vs演义** | 是否区分正史记载与民间演义 | -0.20 | "关羽名不符实"→"历史上关羽的军事能力与民间神化形象不符" |
| **时代背景** | 是否考虑当时的历史条件/局限性 | -0.15 | "秦始皇暴虐"→"以战国末期的标准，秦始皇的统治手段..." |
| **评价维度** | 是否限定评价维度（军事/政治/文化/品德） | -0.15 | "名不符实"→"在军事战略层面名不符实" |
| **史料来源** | 是否引用或暗示史料来源 | -0.10 | 无来源→"据《三国志》记载" |
| **学术争议状态** | 是否说明该观点的学术争议程度 | -0.10 | "名不符实"→"史学界对关羽军事能力存在争议" |
| **民间形象vs史实** | 是否区分民间崇拜/文学形象与历史事实 | -0.10 | "名不符实"→"民间关圣帝君形象与历史关羽存在差距" |

### 历史完整性评分

```
C_history = clamp(1.00 + Σ(要素缺失扣分), 0.00, 1.00)
```

### 历史完整性对真实性的调节

与时事轨道相同的公式：

```
T_adjusted = T_history × (0.50 + 0.50 × C_history)
```

## 历史置信度校准

历史内容的置信度不依赖信源权威度，而依赖**学术共识度**：

| 不确定性因子 | 计算方式 | 说明 |
|-------------|---------|------|
| 史料充分性 | 史料越少，不确定性越高 | 先秦史料稀少→+0.20 |
| 学术争议度 | 争议越大，不确定性越高 | 夏朝存否争议大→+0.15 |
| 时代距离 | 距今越远，不确定性越高 | 商代→+0.10，清代→+0.00 |
| 演义干扰度 | 民间演义越流行，读者越易混淆 | 三国演义极流行→+0.15 |
| 评价主观性 | 价值判断比事实判断不确定性高 | "暴虐"比"统一六国"更主观→+0.10 |

```
C_confidence = 1 - Σ(不确定性因子)
```
