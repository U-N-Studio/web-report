# L2: 基准维度 + 调节因子

> 基准维度（法律道德维度）独立产出分数，是违规判定的核心依据。
> 调节因子不独立产出分数，只对基准维度分值做上下文调节。

## 基准维度：法律道德维度

衡量言论在法律和道德层面的性质，分值范围 **[0, 1]**，保留两位小数，分为 4 段：

| 段位 | 标识 | 分值区间 | 定义 | 判定标准 | 处置策略 |
|------|------|----------|------|----------|----------|
| 违法 | 🔴 | [0.00, 0.25) | 触碰法律红线，对应《规定》第六条违法信息 | 言论内容符合第六条任一款，或违反其他法律法规明文禁止条款 | 立即删除 + 保存记录 + 上报主管部门 |
| 违反道德 | 🟠 | [0.25, 0.40) | 未违法但违反社会公德/公序良俗，对应《规定》第七条不良信息 | 言论内容符合第七条任一款，或违反平台社区公约但未达违法程度 | 标记 + 人工复核 + 限流/折叠/降权 |
| 中性 | ⚪ | [0.40, 0.60) | 不违法不违规，也不具有正向价值 | 事实陈述、普通交流、情绪表达（无攻击性）、中立评论 | 不干预，正常展示 |
| 正向 | 🟢 | [0.60, 1.00] | 符合社会主义核心价值观，具有正向引导作用 | 建设性意见、理性讨论、正能量内容、科普知识、友善互动 | 加权推荐，正向标记 |

### 违法段 [0.00, 0.25) 按违法依据细分

| 子区间 | 违法依据 | 对应严重等级 | 典型内容 | 示例 |
|--------|----------|-------------|----------|------|
| [0.00, 0.07) | 违反宪法 | P0 极严重 | 反对宪法确定的基本原则、危害国家安全、颠覆国家政权、破坏国家统一 | "推翻xx制度" |
| [0.07, 0.14) | 违反刑法 | P0 严重 | 宣扬恐怖主义/极端主义、煽动民族仇恨歧视、侮辱诽谤英烈、诈骗犯罪、传播淫秽物品 | "加群看片，群号xxx" |
| [0.14, 0.20) | 违反治安管理处罚法 | P0 较严重 | 散布谣言扰乱公共秩序、侮辱诽谤他人、传播淫秽信息、赌博 | "xx地方出大事了！"（编造） |
| [0.20, 0.25) | 违反其他法律法规 | P0 一般严重 | 违反《反电信网络诈骗法》《个人信息保护法》《数据安全法》《网络安全法》等 | "代开发票，联系电话xxx" |

## 调节因子1：内容场景宽容度

衡量言论所处视频内容类别对判定的影响。不同内容类别对同一行为的宽容度不同，
例如游戏视频中适度脏话可接受，而儿童动画中任何粗俗语言都应判定违规。

分值范围 **[0, 1]**，保留两位小数，表示 **宽容度**：值越低越严格，值越高越宽容。

### 内容类别与宽容度基准

| 编号 | 内容类别 | 宽容度基准 | 说明 | 典型平台 |
|------|----------|-----------|------|----------|
| C01 | 儿童动画/少儿 | 0.05 | 最严格，任何粗俗/暴力/暗示均不可接受 | B站少儿区、YouTube Kids |
| C02 | 教育科普 | 0.15 | 严格，学术讨论允许引用但不得宣扬 | 网课、知识区 |
| C03 | 新闻时政 | 0.20 | 严格，评论需理性客观，情绪化表达受限 | 新闻频道、时政区 |
| C04 | 纪录片 | 0.25 | 较严格，事实叙述为主，适度讨论可接受 | 纪录片区 |
| C05 | 生活日常 | 0.35 | 中等，日常交流允许口语化表达 | 生活区、vlog |
| C06 | 美食/旅行 | 0.40 | 中等偏宽，氛围轻松，适度调侃可接受 | 美食区、旅行区 |
| C07 | 音乐/舞蹈 | 0.45 | 中等偏宽，粉丝文化允许热情表达 | 音乐区、舞蹈区 |
| C08 | 影视解说 | 0.50 | 中等，剧透/吐槽可接受但人身攻击不行 | 影视区 |
| C09 | 科技数码 | 0.50 | 中等，技术争论激烈但需理性 | 科技区 |

| C12 | 游戏 | 0.70 | 宽松，竞技情绪、适度脏话、垃圾话属于游戏文化 | 游戏区、电竞区 |

### 宽容度对判定的调节规则

| 调节项 | 规则 | 示例 |
|--------|------|------|
| 违法段阈值 | 不调节，法律底线不可因场景降低 | 游戏视频中诈骗链接仍判违法 |
| 违反道德→中性 | 当宽容度 ≥ 0.55 且行为属于**情境惯用语**时，可上调至中性 | 游戏区说"菜鸡"→中性而非违反道德 |
| 中性→违反道德 | 当宽容度 ≤ 0.20 且行为属于**粗俗口语**时，可下调至违反道德 | 少儿区说"卧槽"→违反道德而非中性 |
| 正向判定 | 不调节，正向内容在任何场景均保持正向 | 科普区/游戏区的建设性评论均判正向 |

### 宽容度调节公式

设基准维度原始分值为 `S_base`，内容场景宽容度为 `T_content`：

```
若 S_base ∈ [0.00, 0.25)（违法段）：
    S_after_scene = S_base    // 法律底线不调节

若 S_base ∈ [0.25, 0.33) 且 T_content ≥ 0.55 且 行为∈情境惯用语：
    S_after_scene = 0.40       // 上调至中性段下界（仅P1高风险子区间可上调；P2低风险如标题党/引战本身不属情境惯用语，不触发上调）

若 S_base ∈ [0.40, 0.50) 且 T_content ≤ 0.20 且 行为∈粗俗口语：
    S_after_scene = 0.33       // 下调至违反道德段上界

其他情况：
    S_after_scene = S_base    // 不调节
```

### 内容类别识别规则

| 识别方式 | 优先级 | 说明 |
|----------|--------|------|
| 平台分类标签 | 最高 | B站分区/YouTube分类等官方标签 |
| 视频标题/描述关键词 | 次高 | 匹配类别关键词（如"少儿""游戏""鬼畜"） |
| AI 推断 | 兜底 | 根据视频内容推断类别 |
| 默认值 | 最低 | 未识别时默认 C05 生活日常(0.35) |

## 调节因子2：上下文过错度

衡量评论所针对的对象本身的性质。当被评论对象本身存在违法违规或严重道德缺陷时，
针对该对象的批评性辱骂可适度放宽；反之，针对无辜对象的攻击应加重。

分值范围 **[0, 1]**，保留两位小数，表示 **对象过错度**：值越高表示被评论对象过错越大，对针对它的批评越宽容。

### 对象过错度分级

| 编号 | 对象类型 | 过错度 | 说明 | 典型场景 |
|------|----------|--------|------|----------|
| X01 | 严重违法对象 | 1.00 | 对象行为已构成犯罪，公众愤怒表达可接受 | 贪腐官员、犯罪分子、诈骗团伙被曝光 |
| X02 | 违法违规对象 | 0.85 | 对象行为违法或严重违规，激烈批评可接受 | 劣迹艺人、违规企业、造谣者被揭发 |
| X03 | 严重道德缺陷对象 | 0.70 | 对象行为严重违背公德，谴责性表达可接受 | 虐待动物者、插队拒让者、霸凌者 |
| X04 | 一般道德争议对象 | 0.50 | 对象行为有争议，批评可接受但人身攻击不行 | 服务态度差、商品质量差、言论不当 |
| X05 | 跨边界争议对象 | 0.30 | 对象行为存疑，理性批评可接受 | 观点分歧、审美差异、创作争议 |
| X06 | 普通中性对象 | 0.15 | 对象无明显过错，批评需克制 | 普通创作者、普通作品 |
| X07 | 正向对象 | 0.00 | 对象是正能量/受害者/无辜者，任何攻击应加重 | 英雄模范、受害者、公益行为 |

### 上下文调节规则

过错度调节法律道德维度分值，核心原则：**骂有错者可宽，骂无辜者从严**。

| 调节项 | 规则 | 示例 |
|--------|------|------|
| 针对违法对象的谴责性辱骂 | 过错度 ≥ 0.85 且评论属于**针对性批评**时，违反道德段可上调至中性 | "这个贪官该死"→中性而非违反道德 |
| 针对道德缺陷对象的批评 | 过错度 ≥ 0.70 且评论属于**针对行为的批评**时，违反道德段可上调至中性 | "虐待动物的人渣"→中性 |
| 针对争议对象的批评 | 过错度 ∈ [0.30, 0.50) 时，违反道德段保持不变，不调节 | "这歌真难听"→保持原判定 |
| 针对无辜/正向对象的攻击 | 过错度 ≤ 0.15 且评论含**攻击性表达**时，中性段可下调至违反道德 | "这up主长得真丑"→违反道德 |
| 违法内容不调节 | 任何过错度下，违法段均不调节 | 即使针对罪犯，煽动恐怖主义仍判违法 |
| 非针对性攻击 | 评论与对象过错无关（如性别/地域攻击），不调节 | 对贪官的地域歧视不因对象违法而放宽 |

### 上下文调节公式

设场景调节后分值为 `S_after_scene`，对象过错度为 `F_context`：

```
若 S_after_scene ∈ [0.00, 0.25)（违法段）：
    S_final = S_after_scene    // 法律底线不调节

若 S_after_scene ∈ [0.25, 0.40)（违反道德段）：
    若 F_context ≥ 0.85 且 评论∈针对性批评：
        S_final = 0.40      // 上调至中性段下界
    若 F_context ≥ 0.70 且 评论∈针对行为的批评：
        S_final = 0.40      // 上调至中性段下界
    否则：
        S_final = S_after_scene

若 S_after_scene ∈ [0.40, 0.50)（中性段偏消极）：
    若 F_context ≤ 0.15 且 评论∈攻击性表达：
        S_final = 0.33      // 下调至违反道德段
    否则：
        S_final = S_after_scene

其他情况：
    S_final = S_after_scene    // 不调节
```

### 评论针对性判定

| 类型 | 定义 | 判定方法 | 示例 |
|------|------|----------|------|
| 针对性批评 | 评论内容指向对象的具体过错行为 | 评论主语/宾语指向对象，且谓语与对象过错相关 | "这个贪官贪污几个亿" |
| 针对行为的批评 | 评论批评对象的具体行为而非人格 | 评论针对行为本身，非身份/人格攻击 | "插队就是不对" |
| 攻击性表达 | 评论攻击对象的人格/身份/外貌等与过错无关的属性 | 攻击内容与对象过错无因果关联 | "这up主长得丑" |
| 非针对性攻击 | 评论攻击的是与对象过错无关的群体属性 | 攻击内容涉及性别/地域/民族等 | "xx省的人都是xx" |

### 对象过错度识别规则

| 识别方式 | 优先级 | 说明 |
|----------|--------|------|
| 视频内容定性 | 最高 | 视频本身是曝光/揭发类→对象过错度高 |
| 被评论者历史标签 | 次高 | 平台标记的劣迹/封禁/违规记录 |
| 评论区共识 | 中等 | 多数评论指向同一过错时，推断对象有过错 |
| AI 推断 | 兜底 | AI 根据上下文推断对象性质 |
| 默认值 | 最低 | 未识别时默认 X06 普通中性对象(0.15) |
