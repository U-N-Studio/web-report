# L4: 判定规则 + 置信度校准 + 人工复核

> 各类别的判定遵循"关键词命中 → 语境校验 → 维度评分 → 综合判定"四步流程。
> 本层定义类别特殊规则、联动规则、置信度校准和人工复核流程。

## 类别特殊判定规则

| 类别 | 预扫描关键词示例 | 语境校验要点 | 维度评分倾向 | 特殊规则 |
|------|----------------|-------------|-------------|----------|
| 政治类 | 敏感政治实体名、制度否定词 | 区分学术讨论与煽动；检查是否引用官方表述 | 基准维度倾向违法段低区间[0.00,0.14) | 不做场景宽容调节（政治类内容场景宽容度固定0.50） |
| 暴恐类 | 暴力行为词、恐怖组织名 | 区分游戏/影视描述与宣扬；检查是否新闻报道 | 基准维度倾向违法段 | 描述暴恐事件（新闻）≠ 宣扬暴恐；需意图维度配合判定 |
| 诈骗类 | 转账、加群、链接、中奖 | 区分正常商业信息与诈骗；检查是否有官方认证 | 基准维度倾向违法段高区间[0.14,0.25) | 链接类需额外检测：钓鱼URL特征、短链展开 |
| 色情类 | 性器官词、性行为词 | 区分医学科普与色情；检查内容场景 | 受场景宽容度强调节：医学0.10、成人向0.80 | 医学科普/性教育内容场景宽容度0.10，几乎不降级 |
| 低俗类 | 脏话、歧视词、低俗表达 | 查情境惯用语表豁免；检查是否艺术表达 | 受场景宽容度调节 | 粗俗口语在非正式场景可豁免（调节后≤0.40即可） |
| 侵权类 | 人身攻击词、隐私泄露特征 | 区分批评与侮辱；检查是否公共利益相关 | 侮辱需意图维度配合；隐私需检查信息敏感度 | 公众人物批评阈值高于普通人（上下文过错度调节） |
| 谣言类 | "据内部消息"、无源断言 | 检查真实性维度；查辟谣平台 | 真实性维度为主要判定依据 | T_truth < 0.10 时联动基准维度以"散布谣言"重新评分 |
| 赌博类 | 赌博术语、赔率、下注 | 区分体育新闻与赌博引流 | 基准维度倾向违法段 | 含链接/二维码时严重等级提升 |
| 其他类 | 刷屏特征、引战话术 | 区分活跃讨论与恶意引战 | 基准维度倾向不良段 | 需结合行为模式（频率/重复度）判定，单条评论难判定 |

## 联动规则

| 触发条件 | 联动动作 | 说明 |
|----------|----------|------|
| 时事核验=已证伪 且 被多人引用 | 基准维度以"散布谣言"重新评分 | 已证伪+传播=谣言类违法 |
| 时事核验=已证伪 | 真实性注入"已有辟谣记录(-0.40)"+"与权威信源冲突(-0.35)" | 证伪结果直接决定真实性 |
| 时事核验=有新闻支撑 | 真实性注入"与时事新闻一致(+0.20)"，不触发"与权威信源冲突" | 有新闻支撑是关键转折信号 |
| 意图 I_intent ≥ 0.85 | 还原暗语后重新评分基准维度 | 隐蔽攻击还原后可能命中违法段 |
| 基准 S_final < 0.25 且 客观主观 O < 0.30 | 标记"客观陈述违法事实"，处置降级 | 客观报道违法事件本身不违法 |
| 基准 S_final ∈ 中性 且 意图 I_intent ≥ 0.70 | 标记"隐性不良"，限流 | 表面中性但意图为冷暴力/阴阳怪气（阈值0.70高于L3独立触发阈值0.55，因跨维度联动需更高确信度；I∈[0.55,0.70)仅由意图维度独立折叠，不触发跨维度升级） |
| 完整性 C < 0.30 且 T_truth ≥ 0.40 | 真实性调节：T_adjusted = T_truth × (0.50+0.50×C) | 极度简略+部分真实=误导 |
| 完整性 C < 0.15 且 意图 I_intent ≥ 0.40 | 标记"故意断章取义" | 有意图的断章取义升级处置 |

### 模糊点联动规则

| 触发条件 | 联动动作 | 说明 |
|----------|----------|------|
| 历史轨道产出模糊点 且 S_final ∈ 中性 | 最终判定=模糊点，附加争议说明，降权展示 | 历史争议观点不默认中性 |
| 历史轨道产出模糊点 且 S_final ∈ 违反道德 | 保持违反道德判定，附加"争议观点+道德越线"双标记 | 争议+道德越线，不因争议减轻 |
| 新闻模糊点(S_combined < 0.50) 且 S_final ∈ 违法 | 保持违法判定，附加"信源不足但违法事实明确"说明 | 违法不因信源不足减轻 |
| 新闻模糊点(S_combined∈[0.30,0.60)或T_truth∈[0.40,0.55)或信源矛盾) 且 S_final ∈ 中性 | 最终判定=模糊点，附加信源争议说明，降权展示 | 有新闻但信源不足，不默认中性 |
| 历史模糊点 + 新闻模糊点 同时触发 | 合并为单一模糊点，取min(C_history, S_combined)作为合并置信度，附加双争议说明 | 多源模糊叠加，取最不确定者 |
| 模糊点 且 意图 I_intent ≥ 0.55 | 模糊点升级：附加"争议观点+阴阳怪气/隐蔽意图"双标记 | 有意图的争议观点比无意争议更需关注 |

> **模糊点核心原则**：模糊点**不改变基准维度分值**，只改变**最终判定和处置**。
> 中性→模糊点不是分值变化，而是从"确定合规"变为"不确定是否合规"，必须附加争议说明。

### 双轨道合并规则

当评论同时命中历史轨道和时事轨道时（如"南京大屠杀是假的"），按以下规则合并：

| 场景 | 历史轨道判定 | 时事轨道判定 | 合并结果 | 说明 |
|------|-------------|-------------|----------|------|
| 近代英烈侮辱 | 违法(P04) | 违法(散布谣言) | **违法(P04)** | 英烈保护法优先，取最高严重等级 |
| 近代英烈民间质疑 | 模糊点/违反道德 | 存疑/部分真实 | **模糊点+人工复核** | 双轨道均不确定，必须人工介入 |
| 历史人物争议评价 | 模糊点 | 部分真实 | **模糊点** | 历史轨道不确定性更高，取模糊点 |
| 历史事实+时事关联 | 中性 | 可信/基本属实 | **中性+时事佐证说明** | 时事核验增强了事实基础 |
| 历史事实+时事证伪 | 模糊点 | 确认虚假 | **确认虚假+违反道德** | 时事证伪覆盖历史模糊，升级判定 |

> **合并原则**：
> 1. 违法优先：任一轨道判违法→合并结果为违法
> 2. 证伪优先：时事轨道证伪→覆盖历史轨道的模糊点/中性
> 3. 不确定取并集：双轨道均不确定→合并为模糊点+人工复核
> 4. 严重等级取高：合并后严重等级取两轨道中较高者

## 置信度校准

### 置信度定义

每条评论的每个维度评分附带置信度 C ∈ [0, 1]，表示 AI 对该评分的确信程度。
- C ≥ 0.80：高置信度，可直接处置
- 0.50 ≤ C < 0.80：中置信度，需人工复核确认
- C < 0.50：低置信度，仅标记不处置，必经人工复核

### 置信度计算

```
C = 1 - (不确定性因子之和)

不确定性因子：
  - 模糊信号占比：命中的信号中"部分命中"的比例 × 0.20
  - 信号冲突：正向信号与扣减信号同时命中的数量 × 0.10
  - 语境歧义：语境校验中存在多种合理解释的数量 × 0.15
  - 模型不确定性：AI 输出的 logprob 或 entropy 归一化值（如有）
  - 领域外内容：评论涉及 AI 训练数据外领域 × 0.20
```

### 置信度校准策略

| 策略 | 适用条件 | 动作 |
|------|----------|------|
| 人工复核 | C < 0.50 | 不自动处置，进入人工复核队列 |
| 降级处置 | 0.50 ≤ C < 0.80 且 S_final ∈ 违法段边界 | 按低一级处置（如违法→不良） |
| 标记不处置 | 0.50 ≤ C < 0.80 且 S_final ∈ 不良段边界 | 仅标记，不折叠/删除 |
| 直接处置 | C ≥ 0.80 | 按评分结果直接处置 |
| 历史校准 | 同用户历史评论有相似判定 | 参考历史判定调整置信度±0.10 |

### 置信度报告格式

```json
{
  "comment_id": "xxx",
  "base_score": 0.18,
  "base_confidence": 0.72,
```

## 人工复核流程

### 触发条件

| 触发场景 | 优先级 | 超时 |
|----------|--------|------|
| 违法段判定且置信度 < 0.80 | 🔴 紧急 | 2小时 |
| 确认虚假信息（T_truth < 0.10） | 🔴 紧急 | 2小时 |
| 隐蔽攻击（I_intent ≥ 0.85）需暗语还原 | 🟠 高 | 4小时 |
| 模糊点升级（模糊点 且 I_intent ≥ 0.55） | 🟠 高 | 4小时 |
| 不良段边界且置信度 < 0.50 | 🟠 高 | 4小时 |
| 正交维度独立触发处置 | 🟡 中 | 8小时 |
| 用户申诉 | 🟡 中 | 24小时 |

### 复核流程

```
AI判定结果
  │
  ├─ 进入复核队列（按优先级排序）
  │
  ├─ 复核员领取任务
  │   ├─ 查看原文 + AI评分详情 + 信号命中情况
  │   ├─ 查看上下文（前后评论、用户历史）
  │   └─ 查看相关辟谣/权威信源（如适用）
  │
  ├─ 复核员判定
  │   ├─ ✅ 确认AI判定 → 执行处置
  │   ├─ ⬆️ 升级判定 → 按更高等级处置（如不良→违法）
  │   ├─ ⬇️ 降级判定 → 按更低等级处置（如违法→不良→中性）
  │   └─ ❌ 否定判定 → 撤销AI标记，恢复正常展示
  │
  ├─ 结果反馈
  │   ├─ 写入复核记录（复核员ID、判定、理由、时间）
  │   ├─ 若与AI判定不一致 → 标记为校准样本
  │   └─ 累计校准样本 ≥ 100 → 触发批量校准
  │
  └─ 批量校准
      ├─ 分析校准样本中AI系统性偏差
      ├─ 生成校准报告（哪些类别偏严/偏宽）
      └─ 调整对应类别的阈值/权重（需审批）
```

### 复核员权限

| 角色 | 可复核类别 | 可执行操作 |
|------|-----------|-----------|
| 初级复核员 | 低俗类、其他类 | 确认/降级/否定 |
| 中级复核员 | 所有不良信息类 | 确认/升级/降级/否定 |
| 高级复核员 | 所有类别 | 确认/升级/降级/否定 + 批量校准审批 |
| 主管 | 所有类别 | 所有操作 + 阈值调整审批 + 紧急处置 |
